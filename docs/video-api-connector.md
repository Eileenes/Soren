# 视频 API 连接器

接入依据：[官方接入指南](https://video-api.app.baizhi.cloud/docs/installation.md)及 [VideoAPI Skill](https://video-api.app.baizhi.cloud/docs/skills.md)。

在「设置 → 应用连接 → 视频 API」点击添加，粘贴自己的 API Key，勾选可使用的 Bot，再点击「验证并连接」。无需填写地址、安装客户端或配置厂家密钥。凭据验证只查询当前规格，不提交收费任务；验证成功后 Key 存入系统凭据库，不写入连接元数据。

此连接沿用百智云音乐、生图连接器的 HTTP OpenAPI 适配，固定根地址为 `https://video-api.app.baizhi.cloud/openapi/v1`。提供三个工具：

| 工具 | 行为 | 操作确认 |
| --- | --- | --- |
| `get_video_capabilities` | 查询当前规格、时长范围和积分价格 | 无需 |
| `create_video` | 提交文生视频或公网原图驱动的图生视频 | 需要 |
| `get_video` | 查询任务和积分，完成后下载视频到本机 | 无需 |

从「任务」向获授权的 Bot 交办，例如“先查视频规格和价格，再生成一只猫在雪地里行走的视频，完成后保存到本机”。具体时长、比例及图生视频分辨率以当前 capabilities 为准；不填写时长或图生视频分辨率时，客户端不擅自补默认值。文生视频不发送 `resolution`。每次提交前会再次检查能力接口可用性，查询与下载不会重新创建任务。

图生视频当前接收公网 HTTPS 原图 URL，不接收本地路径或模型编写的 base64。Soren 尚无原图字节上传通道，因此不会伪造上传、处理聊天预览图或悄悄改成文生视频。需要本地原图时，先提供其可访问的原图 URL。

状态查询会在一次工具执行中每隔五秒查询，最多等待约三十秒；未完成则返回真实状态和任务 ID，由 Bot 继续查询。任务整体仍受现有工具轮次与运行时限约束。只有 `succeeded` 表示生成成功；`failed` 显示公开失败信息和 0 积分。排队或执行中的 `points` 为预扣，成功时为最终扣费，实际钱包取决于 Key 所属用户和团队。

成功响应中的 `result.asset_url` 会原样用于下载，下载请求不携带 API Key，不跟随重定向，也不连接本机或内网。视频保存在 Soren 数据目录的 `connectors/video/` 下，返回实际文件路径、大小及 SHA-256。单文件最多 200 MiB，沿用现有下载限制；下载失败时保留生成成功的任务状态，重新查询同一任务即可尝试保存，不应重新生成。临时下载 URL 不作为长期资源保存在工具结果中。

生成 POST 结果不确定时，沿用现有操作记录和幂等回放保护，不自动重复计费请求。鉴权、参数、限流及余额不足使用公开中文提示，不回显原始服务错误、模型、供应商、钱包内部标识或 Key。

开发验证使用本地模拟服务，覆盖凭据校验、Bot 权限、计费确认与重放、实时规格、参数传递、排队/失败/取消及文件保存。未提供真实 API Key 时，不声称已完成真实账号连接或收费视频生成。
