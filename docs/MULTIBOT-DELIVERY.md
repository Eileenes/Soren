# Soren 0.2 本地多 Bot 交付

日期：2026-10-11。当前交付范围为本地多 Bot、文本协作、记忆与部署准备；账号服务和手机中继按用户最新选择暂不部署。

## 已实现

- 内置用户提供的 10 张 PNG 原图，不重绘；额外保留 Soren 默认头像。创建、配置、切换器、对话和任务记录均使用所选头像。
- Bot 创建、编辑、复制配置、暂停和归档；名称、职责、当前供应商下的独立模型 ID、记忆开关、协作对象可配置。
- 职责模板与“完善职责”：调用已连接模型生成 name/instructions 草稿，用户保存后生效。演示模式明确拒绝伪造 AI 配置结果。
- Bot 配置版本持久化，冲突返回 409；任务保存启动时的职责/模型快照，执行时检查当前有效协作授权。
- 对话列表、详情、追加和删除在后端按 Bot 隔离；切换 Bot 时重建聊天和记忆视图，旧请求不混入新视图。
- 记忆查询、召回、标签和缓存使用 Bot 专属 owner namespace。默认 Soren 兼容旧 default-user 记忆；其他 Bot 使用 bot:<id>，不依赖客户端可伪造的 X-User-ID。此阶段仍是本地单用户，不是账号认证实现。
- 手动添加、编辑和删除私有记忆；关闭自动记忆后不再为该 Bot 召回/提取，已有记录仍可管理。
- 共享资料独立保存，用户明确选择可读 Bot；普通对话只读当前 Bot 获准的资料，协作取所有参与者授权交集。
- 协作任务：邀请最多 3 个互相授权的 Bot，依次执行职责并传递前序文本结果，最后由发起 Bot 汇总。不会读取 Bot 私有记忆，也不会自动把成果写入长期记忆。
- 任务持久化、排队、状态/步骤查看、取消、重启后显式继续；同请求 ID 去重，最多同时运行 3 个任务，最多排队/运行 20 个，单任务 20 分钟上限。
- 执行前后检查授权；中途撤销协作或共享资料变化会停止后续步骤；取消后迟到结果不能覆盖取消状态。
- Anthropic 适配修复：合并职责和记忆 system 消息，避免后一个覆盖前一个。
- 手机布局、PWA 安装清单和公开界面资源缓存；设置明确显示手机联动“待部署”。服务工作线程不缓存 API 或身份数据。

## 当前没有实现的能力

- 云账号、验证码、设备信任、中继和手机远程执行；仅响应式布局不能实现跨设备。
- 自动选择伙伴、递归创建子 Agent、多轮自主协商、工具调用或外部写操作审批。当前协作是用户指定参与者的有限文本流水线。
- Gmail/日历授权、邮件真正发送、图片/视频生成、定时任务。
- 不同 Bot 同时使用不同服务商凭据；当前可覆盖同一已连接服务商下的模型 ID。
- Bot 永久删除、完整知识库集合及备份恢复界面；目前提供暂停/归档与独立记忆删除。
- Keychain 尚未接入，模型凭据仍在权限为 0600 的本地配置中。

这些边界在界面和交付说明中保留，不用演示输出冒充真实工具结果。

## 验证

- 前端 TypeScript 与生产构建通过；22 项原有测试通过。
- Go 全量测试通过；新增 Bot 版本冲突、协作授权、共享交集、请求去重、取消、授权撤销、重启暂停、会话/记忆隔离、Anthropic 多 system 消息回归覆盖。

- 1360×880 桌面明/暗、390×844 手机检查通过，手机无横向溢出。配置弹窗使用内部滚动并固定保存按钮。
- 签名校验与 DMG 完整性校验通过（ad-hoc 签名，尚未 Apple 公证）。
- 最终 .app 已由 macOS 启动；目标进程存在，/api/health 返回 ok，/api/bots 正常返回默认 Soren。原生截图仍未验证，不以网页截图代替原生截图。
- 无真实模型或第三方账户参与测试。职责草稿/真实模型协作需用户配置 API Key 后使用。

### 测试数据隔离修正

首次界面验收脚本误用了 DATA_DIR，Go 实际读取 SOREN_DATA_DIR，导致测试数据进入本地库。发现后通过 SQLite backup 先保存完整备份，再按本轮确切的 Bot ID 和输入内容清理 3 个测试 Bot 及关联测试记忆/任务/共享资料；保留默认 Soren 和原有历史。随后明确设置 SOREN_DATA_DIR 与 SQLITE_PATH，在临时数据库重新完整验收通过。

应用迁移增加 Bot 归属前也自动保存 `.before-bots-*` SQLite 备份。测试清理备份保存在 `~/.soren/soren.db.before-qa-cleanup-*`；未删除这些备份。
