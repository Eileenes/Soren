# Soren 界面重构与验收

日期：2026-10-11。截图来自实际运行的 React 页面。接口功能验证使用临时测试数据库；界面截图未填充虚构的业务结果。

## 本轮交付

视觉采用暖白 / 薄荷青绿 / 柔金渐变，深色采用炭黑与石墨灰分层，辅以薄荷青和微蓝光晕，品牌是有圆眼和眨眼表情的原创小伙伴。界面使用统一语义色，不复制参照产品的标志或头像。

- 对话：精简首页、可编辑的建议提示、快捷提示菜单、模型设置入口、真实演示状态、消息复制与 Markdown。
- 侧栏：新建对话、历史搜索、删除确认、记忆计数；手机改为抽屉，支持遮罩、Escape、焦点循环与关闭后焦点恢复。
- 记忆：搜索、类型/重要度筛选、统计、分页与删除。
- 连接：飞书/钉钉已有能力与配置说明；邮件、日历、Notion、创作工具明确为规划项。
- 设置：桌面 IPC 真实保存 provider/endpoint/key 并重启服务；明暗主题、模型参数、数据目录和服务诊断。浏览器预览没有宿主权限，凭据保存被禁用。
- 原创 SVG、透明头像、无灰底大脸渐变应用图标、ICNS/ICO、多尺寸 PNG、移动端图标。

非敏感偏好存储在 localStorage；API Key 不进入浏览器存储，桌面端保存至 `~/.soren/provider.json`（0600）。尚未接入 Keychain。配置保存成功代表本地保存和服务就绪，远端模型凭据有效性需要发消息验证。

## 验证

- `npm --prefix frontend run build`：TypeScript 与生产构建通过。
- `npm --prefix frontend test`：22 项测试通过，包含界面导航、主题、记忆操作及请求竞态。
- `go test ./...`：全部通过。新增默认 loopback、CORS、否定偏好保留、完整记忆值注入、会话事务删除测试。
- 桌面宿主：配置保存/密钥保留/端点验证等 Rust 测试通过；包的实际验证见 `MACOS-BUILD.md`。
- Chrome + Playwright：1360×880 桌面明/暗、390×844 手机布局；无 JS 页面异常，无手机横向溢出；首屏四个简洁操作入口完整可见；主题刷新后保留；抽屉焦点与 Escape 正常。
- 真实本地 API：发送消息、接收明确标记的演示回复、记忆写入/查询、历史读取；测试使用临时目录，未使用真实模型 Key 或第三方账户。
- 设置页 IPC 模拟交互：同接口留空保留旧 key；更换接口要求新 key；保存后清空输入；key 不落 localStorage。此验证不代表真实供应商已联网认证。

## 当前边界

本轮完成可运行的桌面基础、界面与品牌，未实现 Agent 执行/工具调用/邮件发送/媒体生成/定时任务。模型调用仍为一次性文本响应，移除了假逐字播放。飞书/钉钉需要真实账号配置验证，且目前未共享桌面的记忆处理链路。手机适配不等于 iOS/Android 安装包；本地默认不接受局域网访问，远程接续需要后续安全配对和网关。

参照依据和分阶段路线见 [架构审查与演进](ARCHITECTURE-REVIEW.md)。本次新增 [多 Bot 与移动端联动方案](MULTI-BOT-AND-MOBILE-PLAN.md)，按用户要求等待确认后实施。

## 本次反馈修订

- 图标移除灰白底板与额外外边距，改成渐变脸部铺满，更新 ICNS/ICO 和移动端 PNG。
- 保持浅色森林风格；深色改成炭黑背景、分层卡片和浅薄荷操作色。
- 删除首页英文标语、长介绍、重复卡片描述、侧栏宣传卡、输入区口号和连接页宣传横幅；设置标题改为直接的功能名称。
- 保留离线提示、未连接模型的演示标识、凭据说明和错误信息。
