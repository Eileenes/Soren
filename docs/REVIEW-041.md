# 0.4.1 项目审查与修复

审查日期：2026-10-12。范围包括 Go API、Bot/任务/记忆隔离、连接器审批与凭据、手机配对/中继、React 状态管理、Tauri 配置与打包、依赖和待上传文件。静态检查和自动化验证不能保证不存在未知问题。

## 已修复

| 问题 | 修复 |
| --- | --- |
| 模型客户端默认跟随重定向，可能转发凭据 | OpenAI、Anthropic 与连接器 HTTP 请求拒绝重定向；补充回归测试 |
| 模型服务错误正文可能回显 Key/提示词并写入任务记录 | 错误只返回状态与安全提示，不转存服务商错误正文 |
| 模型请求缺少统一时间和响应大小限制 | 90 秒上限、4 MiB 响应上限 |
| Anthropic 地址包含 `/v1` 时重复拼接版本路径 | 统一兼容带或不带 `/v1` 的地址 |
| 仅调整温度/长度等聊天参数时退回过时模型 | 保留后端配置的默认模型，再应用显式模型覆盖 |
| 旧对话追加消息未更新最近排序 | 保存消息与更新对话时间放在同一事务 |
| SQLite 数据在独立后端启动时可能使用宽松文件权限 | 新库和已有数据库、WAL/SHM 限制为当前系统用户可读写 |
| Webhook 模式缺少认证信息仍可启动 | 缺少飞书校验 Token/Encrypt Key 或钉钉加签密钥时拒绝启动和处理 |
| 钉钉回复地址仅检查 HTTPS，可向非平台地址发送 | 限制到官方 `oapi.dingtalk.com`，拒绝用户信息、异常端口和重定向 |
| 手机恢复联网后残留连接失败提示 | 将网络状态错误与操作结果不明的错误分开，恢复时仅清除前者 |
| 手机提交任务期间切换 Bot 可能混入旧响应 | 提交期间禁止切换 Bot；补充交互回归测试 |
| 旧版网络、数据库、前端开发测试依赖有已知漏洞 | 升级受影响依赖并锁定版本，Go 最低版本更新为 1.26.9，Node 为 22.12 |

## 验证与剩余边界

- Go：全量竞态测试和 `go vet` 通过；涵盖隔离、审批、重放防护、撤销、持久化与新增回归用例。
- 前端：33 项测试通过，TypeScript 与生产构建通过。
- 桌面 Rust：8 项测试通过。
- 浏览器端到端：独立临时数据库、本地真实加密中继、Mac 确认配对、手机发起任务、Mac 可见和设备撤销通过；390px 手机视口无横向溢出、无页面异常。使用本地回显模型，未调用外部模型。
- 0.4.1 macOS Apple Silicon App/DMG 构建通过，已验证本地签名及 DMG 完整性；未进行 Apple 公证。
- `govulncheck`：业务代码可达漏洞 0，已导入包漏洞 0。模块级剩余 1 项是未导入的 `x/crypto/openpgp` 停维护告警；本项目使用 NaCl，不使用 OpenPGP。
- `npm audit --omit=dev`：0 项。全部依赖扫描剩余 7 项（5 high、2 moderate），都在 Tailwind 3 的构建依赖链上，核心为 braces 和 postcss-selector-parser；不进入发行应用的 JavaScript。构建仅处理受信任的仓库源码和固定 glob，禁止将用户输入传入构建配置。未通过忽略规则隐藏告警。
- 保留 Tailwind 3 是为了当前旧版 macOS/iOS WebView 兼容范围；[Tailwind 4 官方迁移说明](https://tailwindcss.com/docs/upgrade-guide#browser-requirements) 要求 Safari 16.4+。全面迁移需同时提高最低系统要求并做视觉回归，未在此次安全修复中悄悄改变产品兼容范围。[braces 公告](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) 当前无修复版本。
- RustSec 锁文件检查：桌面和移动均为 0 项 vulnerability；仍有 GTK/Linux 依赖的 `glib` unsound 和 `proc-macro-error` 停维护告警。当前验收范围为 macOS/iOS，Linux 不作发行验收。检查使用官方 RustSec 数据库；此次未执行 yanked registry 检查。
- 外部 Gmail/Notion/MCP 真实账号操作、iOS 真机扫码与公网部署未在此次调用真实凭据验收。当前 Mac 本地功能可用；公共中继、正式签名和移动分发仍未上线。
