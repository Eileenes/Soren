## Soren 0.4.3 · 开发预览 / Developer Preview

### 下载 / Download

- **Mac（Apple Silicon）**：下载 `Soren-0.4.3-macOS-arm64.dmg`，将 Soren 拖入「应用程序」。支持 macOS 12 及以上。
- **Mac (Apple Silicon)**: download the DMG and drag Soren into Applications. Requires macOS 12 or later.
- 安装包为本地签名，尚未经过 Apple 公证。/ The installer is ad-hoc signed and is not Apple-notarized.
- 下载同版本校验文件，并在安装包目录执行：/ Verify the download with:

```sh
shasum -a 256 -c SHA256SUMS-0.4.3.txt
```

### 更新 / Changes

- 新增百智云 AI 音乐、AI 生图、云浏览器和设计提示词连接器；新增 Agent 工具包入口，填写 API Key、选择 Bot 后自动发现 MCP 工具。
- Added Baizhi Cloud music, image generation, cloud browser and design prompt connectors, plus an Agent Toolkit preset with API key setup and MCP tool discovery.
- 应用连接展示官网 Logo，并支持从桌面端打开对应接入页面；凭据保存在本机系统凭据库，工具沿用 Bot 权限与调用确认流程。
- Connection cards now use official logos and open the providers' setup pages. Credentials stay in the system credential store, with Bot permissions and existing tool approval rules preserved.
- 侧栏以 Bot 为入口，显示最近对话摘要；新增 Bot 与对话搜索、对话历史入口，以及任务运行时摇头、眨眼的头像动效。
- Added Bot navigation with recent conversation previews, Bot/conversation search, conversation history and animated avatars during active tasks.
- 精简聊天输入框与顶部标题；Bot 卡片及记忆卡片采用紧凑布局，记忆可点击查看完整详情，复制、编辑、删除统一为图标按钮。
- Simplified the chat composer and title bar. Bot and memory cards are more compact; memory details open on click, with icon controls for copying, editing and deleting.
- 统一界面按钮尺寸，改进窄屏布局及跨 Bot 数据请求的作用域。
- Unified button sizes and improved narrow-screen layouts and Bot-scoped data requests.

### 使用说明 / Notes

- 第三方连接器需要相应服务的有效凭据，具体工具和计费由服务商及账号权限决定。本次未使用真实 Agent 工具包 API Key 进行账号连接或付费工具调用。
- Third-party connectors require valid provider credentials. Available tools and charges depend on the provider and account permissions. No live Agent Toolkit account connection or paid call was performed for this release.
- **iOS 尚未开放下载，完整手机聊天同步仍处于方案阶段。** 此版本不包含可安装的 iPhone IPA，也不承诺 Mac 离线时仍可远程对话。
- **iOS downloads are not available; full mobile chat synchronization remains planned.** No installable iPhone IPA is included, and remote chat requires further implementation and deployment.
