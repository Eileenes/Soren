# Soren 0.4.4

## 聊天调用应用

- 个人空间和公司空间的 Bot 单聊、群聊都接入现有工具运行时；只向模型提供该 Bot 获得授权的应用工具。
- 聊天内展示调用记录、批准/拒绝、继续和取消。音乐生成等付费操作及 MCP 调用沿用逐次确认规则。
- 执行记录与消息持久化关联，刷新和重连后恢复状态；重试同一请求不重复创建执行。服务重启后的未完成执行需要手动继续，外部结果不明时不自动重试。
- 群聊遇到操作确认时暂停本轮讨论。完成或取消该操作后，发送下一条消息继续讨论。
- 内置连接器下载的文件保存为独立成果，通过当前用户、Bot 和执行记录鉴权后下载。桌面版保存到 Soren 数据目录的 `exports` 文件夹并在 Finder 显示。
- MCP 和公开下载地址支持企业配置的出站代理，同时保留目标地址检查。

## 更新与验证

服务器与桌面客户端需要同时更新。旧客户端保持原来的文字聊天协议；新客户端显式启用聊天工具执行。

本次包含数据库新增字段及表。个人 SQLite 在聊天消息迁移前自动备份；企业 PostgreSQL 使用新增表/列迁移，不修改现有连接凭据。

自动化验证涵盖模拟音乐/MCP、批准/拒绝/撤权、取消、重试去重、群成员授权、成果下载及 PostgreSQL 用户隔离。真实 `deepseek-flash` 网关已验证工具调用及结果回传两轮请求。各外部应用的真实凭据和业务动作仍需部署后逐项试用；这些测试不代表全部应用均完成真实联调。

本地构建的 macOS Apple Silicon 试用包使用临时签名，未做 Apple 公证。此版本未构建或发布移动端安装包。
