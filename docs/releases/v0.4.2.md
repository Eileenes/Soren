## Soren 0.4.2 · 开发预览 / Developer Preview

### 下载 / Download

- **Mac（Apple Silicon）**：下载下方 `Soren-0.4.2-macOS-arm64.dmg`，将 Soren 拖入「应用程序」。支持 macOS 12 及以上。
- **Mac (Apple Silicon)**: download the DMG below and drag Soren into Applications. Requires macOS 12 or later.
- 安装包为本地签名，尚未经过 Apple 公证。/ The installer is ad-hoc signed and is not Apple-notarized.
- 下载同版本校验文件，在安装包目录执行：/ Verify the download with:

```sh
shasum -a 256 -c SHA256SUMS-0.4.2.txt
```

### 更新 / Changes

- 桌面「设置 → 关联设备」增加 iOS 安装入口，支持 TestFlight / App Store 链接和安装二维码。
- Added an iOS installation entry under Settings → Linked devices, with TestFlight / App Store links and installation QR codes.
- 新增按版本标签自动构建、验证及发布 GitHub Release 的工作流。
- Added a version-tag workflow to build, verify, and publish GitHub Releases.
- 中英文 README 提供下载及发布说明。/ Chinese and English READMEs include download and publishing instructions.

### iOS 状态 / iOS status

**iOS 尚未开放下载。** Apple 签名构建、TestFlight 邀请链接和公共连接服务仍需发布方完成；本版本显示待开放状态。没有上传模拟器包或未签名 IPA 冒充可安装版本。

**iOS downloads are not available yet.** A signed Apple build, TestFlight invitation, and public connection services are still pending. The desktop entry shows that status; no simulator package or unsigned IPA is offered as an iPhone installer.

安装 iOS 后仍需在 Mac 生成配对码并确认关联，Mac 保持在线。/ After iOS becomes available, pair it with your Mac and keep the Mac online.
