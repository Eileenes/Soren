# Soren 0.4.5

## 应用连接后，当前空间的所有 Bot 可用

- 移除连接时的 Bot 勾选和逐 Bot 连接权限入口。连接并启用后，当前空间内所有 Bot、群聊及任务都可以使用，包括以后新建的 Bot。
- 已有连接自动按新规则生效，不需要重新填写 Key；旧版保存的 `allowedBots` 名单不再限制连接的使用范围。保留旧数据库字段用于兼容，不删除已有凭据。
- 连接可整体停用、启用或断开。停用或断开后，所有 Bot 都不能再调用；变更连接版本会使等待批准的旧操作失效。
- Bot 动作策略、暂停/归档状态、群成员资格及逐次操作确认仍然生效。音乐生成等付费操作和 MCP 调用仍需要确认。
- 共享范围是当前用户的当前空间；不会跨公司用户、跨公司空间或跨个人/公司空间共享凭据。调用记录、确认和成果仍绑定执行 Bot。

## 更新与验证

客户端与企业服务端均需更新。旧客户端的 Bot 选择字段会被新版服务端忽略，请使用 0.4.5 客户端查看正确的共享范围。

回归覆盖已有空名单/旧名单连接、新建 Bot 直接调用、群聊各成员使用同一连接、连接停用、动作禁用、操作确认及 PostgreSQL 用户空间隔离。外部服务使用模拟接口验证，真实音乐和 OctoBus 的业务操作仍需部署后试用。

本地 macOS Apple Silicon 安装包使用临时签名，未做 Apple 公证。本次未构建或发布移动端安装包。
