# 0.4 手机联动实现与交付边界

2026-10-12。正式产品方向：用户安装 Mac 与手机端，扫码、在 Mac 核对确认码，访问同一空间。用户不部署服务器、不需要 Tailscale、不强制登录 GitHub。产品方部署公共连接服务。

## 本轮实现

- Mac 设置新增「关联设备」：开关、5 分钟一次性二维码、待确认手机及确认码、设备列表、解除关联。最多 10 台手机，每次新建二维码作废旧二维码。
- `backend/internal/mobile`：设备身份、配对授权、有限操作网关、持久化写入回执。未配对或已撤销设备无法执行操作，也不能读到之前缓存的请求结果。
- `backend/cmd/relay`：独立无账号中继，Mac 主动连接，手机可从不同网络提交加密消息。中继用 HTTPS 长轮询，当前没有 WebSocket 依赖。中继重启会中断在途连接，Mac 自动重新连接。
- 加密由 Go NaCl box 与 TweetNaCl 互通，使用设备公钥加密并认证消息。二维码包含 Mac 公钥、短期配对秘密和路由地址；模型密钥与连接器凭据不进入二维码或中继。确认码在两端独立计算。
- 中继不知道业务正文、配对秘密及手机私钥，但可观察 IP、主节点路由 ID、手机公钥、消息大小和时间。本轮验证协议互通、篡改拒绝和信任边界，不等于独立密码学审计。
- 手机页面 `frontend/mobile.html`：关联、选择 Bot、发起任务、任务结果/步骤、审批工具调用、继续/停止、查看成果和当前 Bot 记忆。前台定期刷新，恢复前台时刷新。
- 独立 `mobile/src-tauri` iOS 工程：相机扫码、设备凭据存 iOS Keychain。手机不携带 Go 后端、模型配置或桌面菜单栏。
- Web 入口便于验证，只保留本次页面的设备身份；不将私钥写入 localStorage。关闭页面后需要重新配对。它不是已上架的手机 App。

## 当前边界

- 公共域名、中继主机、TLS 和正式移动分发尚未配置；默认 Mac 构建明确显示「远程连接服务尚未上线」，不会生成不可用二维码。开发模式可用独立的本地中继验证完整协议。
- iOS 模拟器包与真机签名包不同。相机扫码必须在真实手机上验收；TestFlight/App Store 分发需要产品方的 Apple 开发者签名和上架配置。
- Android 安全存储和原生工程尚未交付，构建入口显式阻止没有安全存储的 Android 包，避免退回内存伪装为已保存身份。
- 当前手机端覆盖任务与记忆；完整聊天页、手机创建/编辑 Bot、连接器配置、系统推送、离线编辑不在本轮移动入口中。配置仍在 Mac 完成。
- Mac 需运行、联网且未休眠。中继不执行任务，也不提供云端记忆备份。手机后台时不假设长连接持续运行。
- 配对设备拥有该本地空间的全部 Bot 任务/记忆访问及审批权；Mac 确认时显示权限范围。细粒度只读设备或逐 Bot 设备授权尚未实现。
- 解除关联阻止新的访问；不能收回手机此前已看到的内容，也不会自动取消已经接受的任务。
- 任务请求包含业务去重编号，移动网关对写操作先持久化预约、再执行、再记结果。中途崩溃留下不确定回执时拒绝重放并要求刷新核实；不会自动重发邮件。
- 手机设备凭据保存在 Keychain；Mac 身份目前保存在数据目录的 0600 文件，目录 0700。Mac 本地回执可能包含结果，和现有本地数据库使用相同的数据边界。

## 关键文件

- `backend/internal/mobile/service.go`：配对、授权、加密、本机 API 允许列表、回执与中继客户端。
- `backend/internal/relay/relay.go`：路由、主节点持有证明、在线检测、超时、限流、请求/队列上限。
- `frontend/src/components/MobileDevices.tsx`：Mac 关联设备界面。
- `frontend/src/mobile/`：独立移动入口与加密传输。
- `mobile/src-tauri/`：iOS 原生壳、扫码权限与 Keychain 命令。
- `deploy/relay/`：Docker、Compose 与 Caddy TLS 反向代理配置。

## 发布前验收

公网部署后，在真实 iPhone 使用蜂窝网络和不同 Wi-Fi 验证扫码、核对、审批、断线重连和 Mac 休眠；验证证书、原生 WebView Origin、Keychain 持久化与卸载重装行为。正式发布还需要公共服务的滥用防护、容量与故障演练；当前服务是有明确容量上限的单实例版本，不支持无状态多副本随机负载均衡。

## 本轮验证结果

- Go 全量测试通过；移动网关与中继的 race 测试通过，覆盖配对确认、设备隔离、撤销、过期/篡改消息、接口允许列表、同请求重放、重启回执和真实 HTTP 中继往返。
- 前端 31 个测试通过，含加密传输、身份替换拒绝、离线提示、二维码验证和不写浏览器持久存储。
- Playwright 使用真实 Go 后端和真实中继，独立测试目录、演示模型：手机提交任务可从 Mac API 读到，设备撤销立即拒绝后续访问；Mac 页面真实二维码渲染与批准流程通过。无页面异常，390 像素视口无横向溢出。
- iOS arm64 模拟器归档构建、安装和启动通过。已补充标准 Xcode Keychain 权限，启动读取凭据不再报错。未用真实相机扫码，未验证真机 Keychain 写入/重启恢复，不宣称已上架。
- 预览：`docs/previews/mobile-040-linked-light.png`、`mobile-040-linked-dark.png`、`mobile-040-ios-simulator.png`、`mobile-040-desktop-devices.png`。
- iOS 初始化工具更新了本机 libimobiledevice 及其 Homebrew 依赖（包括 OpenSSL）；没有修改系统安全策略或使用个人签名身份发布应用。

真实链路浏览器回归脚本为 `scripts/qa/mobile-e2e.mjs`。按部署文档启动开发中继/独立测试后端/前端后运行 `node scripts/qa/mobile-e2e.mjs`。仅对独立测试目录执行：脚本会开启手机连接、配对测试手机、提交演示任务并撤销该设备。可以用 `SOREN_QA_API` 指定测试后端。需要本机 Chrome 与前端依赖。
