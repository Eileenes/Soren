# Soren 0.3.2：本地配置与界面调整

## 本地直接使用

不需要 GitHub 账号、OAuth 应用或自行部署 Soren 服务。安装应用 → 设置模型 → 创建 Bot / 对话 / 任务。设置中的 GitHub 登录表单已移除；旧身份记录未删除，也不影响使用。Gmail 等外部服务仍按其自身规则授权。

## 模型列表

在「设置 → 模型」填写接口地址和 Key，点击「获取模型」，从应用内菜单选择，再点击「保存模型连接」。也可以手动填写模型 ID。已保存的同一服务商/地址可以留空 Key；换地址后必须填写对应 Key。

支持 OpenAI 兼容的 `GET <baseURL>/models` 和 Anthropic 的 `GET /v1/models`，包含分页。官方接口参考：[OpenAI Models](https://developers.openai.com/api/reference/resources/models/methods/list)、[Anthropic Models](https://platform.claude.com/docs/en/api/models/list)。服务商返回的列表可能含非对话模型，应选择支持对话、任务所需工具调用的模型；获取成功不等于已经验证推理能力。

列表获取由桌面 Rust 执行，Key 不回传 UI、不写入浏览器存储；禁止重定向，限制超时、响应大小和分页数。请求只读取模型目录，不启动模型推理或重启服务。无列表、鉴权失败、格式不兼容均有错误提示，并保留手动输入入口。更换服务商/地址/Key 后清除旧列表，旧异步响应不能覆盖新配置。

保存后模型名称与服务商配置一起落盘，通过 `SOREN_MODEL` 传给 Go。对话、新任务、职责草稿和渠道使用全局默认模型；单个 Bot 的明确模型配置优先。切换会重启本地服务，原任务按现有恢复逻辑处理。

## 界面

- Bot 切换、Bot 状态、记忆筛选、语言和模型列表均使用应用内下拉样式。支持方向键、Enter、Escape、键入定位和点击外部关闭；菜单不被滚动容器裁切。
- 左下角图标去掉包裹边框，设置按钮统一悬停和选中状态。
- 顶部连接状态仅展示图标，悬停提示与读屏标签保留。
- 最近对话为空时保留空白，不显示横线、加载或空状态文案。
- 外观支持浅色、深色、跟随系统。新安装默认跟随系统，已有明确选择保持不变；监听系统变化，手动主题不会被覆盖。

## 验证范围

27 项前端测试、Go 全包测试、8 项 Rust 测试通过。原生模型列表测试使用本地 HTTP 服务，覆盖兼容协议、认证头、分页、去重、错误响应、重定向阻止、旧配置兼容和模型持久化。

浏览器验证覆盖获取/选择/保存、接口更换失效、手动输入、主题实时变化、无原生 select、空对话区域、图标状态与 390px 布局。该界面验证模拟 Tauri IPC；没有使用用户的真实服务商 Key 或声明实际服务商联调成功。截图在 `docs/previews/settings-032-*.png`。

macOS 安装包仅 Apple Silicon，延续 ad-hoc 签名，未公证。手机扫码配对仍待实现，详见 [手机方案](MOBILE-PAIRING-RESEARCH.md)。
